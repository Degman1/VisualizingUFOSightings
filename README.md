Data Visualization: UFO Sightings
Our code is is all of the files within the `Components` Folder as well as `App.xx` related files and the `index.xx` files, and some changes were made to `package.json`, and everything within the `cleaned` folder is our data. We used no libraries except for `d3.js` and the `React` framework. 

Website: https://degman1.github.io/VisualizingUFOSightings/
Screencast: https://www.youtube.com/watch?v=Z5Z8Ox472Oc&feature=youtu.be

This project explores patterns in reported UFO sightings across the United States using interactive data visualizations. Users can explore trends over time, investigate individual sightings in detail, and compare sightings with socioeconomic metrics across states.

We built a website with three main interactive tabs:
1. Trends: High-level view of total sightings by state and over time.
2. Individual Sightings: Fine-grained view of individual reports with metadata and testimonies.
3. State Comparisons: Analyze how state-level factors like education or poverty correlate with sightings.

All of our original code is located in the following files and directories:
1. Components/: All custom components used to build the visualizations.
2. App.js and related style/layout files: Main routing and structure logic.
3. index.js: Entry point for rendering the app.
4. package.json: Contains minor edits for library dependencies and build scripts.

We used only the following libraries:
1. React: For component-based frontend structure.
2. D3.js: For rendering and manipulating SVG-based data visualizations.

All of our website features are designed to be very intuitive, and any explanation for how to use them is on the website itself. All of the maps are interactive, draggable, and zoomable. The remainder of the charts are updated based on the maps and how you manipulate the maps.
